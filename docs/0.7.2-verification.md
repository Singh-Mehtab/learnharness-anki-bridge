# Anki Bridge 0.7.2 verification

The previous writer treated Recall as applying an idea to a new case. It could put `1 fm = 10⁻¹⁵ m` in the question and ask for arithmetic, leaving the prefix untested. Fact and Equation now ask for the missing fact or equation directly. The Anki note type is still Basic.

Steps, Apply, Why, Compose and Contrast are opt-in. The writer normally skips numerical values of physical constants, except useful working conversions or when a flag explicitly asks for the value. The toggle guides the writer; it does not classify cards after generation. There is no session cap. Flagged ideas, including flags without a note, can exceed the normal per-idea cap up to 12 cards if there is enough material.

The upgrade backs up schema 4 before moving to schema 5. It resets the card-type selection to Fact and Equation, keeps the per-idea cap and model override, and leaves old Recall cards and frozen requests alone. See [rollback instructions](install.md#upgrade-without-losing-data).

## What was checked

- A Sonnet run at medium effort on the lecture used for tuning produced 39 cards for review. The learner marked 26 keep, 10 small edit, one big edit and two drop. The final prompt was run on that same lecture and spot-checked against those edits; it was not scored again. The older Opus run used a different prompt, so these runs do not isolate a model effect.
- Automated tests cover the new defaults, model and thinking selection, legacy state and worker recovery, flags without notes, preflight caps and duplicate handling. Live generation suppresses exact repeats across requests only when it can match an eligible unsent draft or approved card. An Anki note may have been edited since it was sent. Similar wording is left for review rather than automatically removed.
- The README screenshots show a scratch LearnHarness 0.6.1 in Chromium with synthetic lecture data and a stub AnkiConnect. The browser showed both default types checked, the optional types off, and the new Fact and Equation drafts with rendered answers.

## Still untested

No held-out lecture was run. The bench uses the writer outside the app. This version has not yet gone from a live model in LearnHarness to a real Anki profile. Try that flow before treating it as a public release.
