# Changelog

Newest first. Versions before 0.9.0 were merged to `main` for personal use while the repository was private. Verification notes for older versions are in `docs/`.

Upgrades state to schema 9 with a pre-upgrade backup. |

See [verification and limits](docs/0.7.2-verification.md). |
| 0.7.1 | [#35](https://github.com/Singh-Mehtab/learnharness-anki-bridge/pull/35) | Fixes for issues #30 to #33 and two gaps left open in #17 and #19. Deck and tag fields show `::` as two colons. A green panel confirms each send with the deck, tags and a Show in Anki button. The flag dialog confirms a flag or note and closes itself. A flagged idea without cards also says No cards, and an older deck lookup can't replace a newer one. Recall's description now matches what the writer does. 227 tests, typecheck and build pass. See [verification and limits](docs/0.7.1-verification.md). |

The writer prompt now asks for MathJax on every variable and prefers display maths. 215 tests, typecheck and build pass. See [verification and limits](docs/0.7.0-verification.md). |
